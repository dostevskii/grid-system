# Grid System font notices

이 디렉터리는 앱과 HTML/CSS 내보내기에 쓰는 서체의 라이선스와 출처를 보존합니다.

- Google Fonts 8종, Pretendard, Wanted Sans: 각 OFL 1.1 전문 파일을 확인하십시오.
- 열린명조·열린고딕: [Yeolrin-NOTICE.md](./Yeolrin-NOTICE.md)의 원저작자, 지정 배포 저장소의 제작사 확인 안내, 공식 라이선스 전문 부재를 확인하십시오.
- 모든 실제 바이너리와 SHA-256 값은 [`/fonts/ASSET-SHA256.json`](../fonts/ASSET-SHA256.json)에 기록됩니다.
