# 열린명조 · 열린고딕 출처 안내

이 파일은 `hyunbinseo/yeolrin` v1.0.0 배포본의 WOFF2입니다. 원저작자는 서울산업진흥원(현 서울경제진흥원)이며, 윤디자인이 전용서체로 디자인했습니다.

사용자 지정 배포 저장소의 README는 서울경제진흥원 윤리경영실의 국민신문고 처리 정보(신청번호 `1AA-2505-0517144`)와 제작사 윤디자인 확인을 근거로, 이 글꼴이 오픈소스형 개발 프로젝트이며 라이선스 제약이 없다고 안내합니다. 같은 README는 릴리스 ZIP의 TTF·WOFF2 직접 사용과 jsDelivr 웹폰트 사용 예시도 제공합니다. Grid System은 이 공개 안내를 근거로 이 WOFF2를 사용합니다.

이 저장소에는 별도 OFL 또는 원저작권자의 라이선스 전문이 포함되어 있지 않습니다. 따라서 이 고지는 OFL이나 별도 조건을 새로 주장하지 않으며, 특수 용도·정책 변경·별도 배포 조건은 권리자와 최신 공식 안내로 다시 확인해야 합니다. FONCO의 일반 상품 정책은 존재하나, 위 특정 무료 글꼴의 README 안내보다 자동으로 우선한다고 단정하지 않습니다.
